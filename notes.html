Notes

The more important changes to this website and its experiments, newest first.

Minesweeper: keyboard play and chording

November 10, 2026

Minesweeper can now be played with the keyboard, and clicking a revealed number whose mines are all flagged opens the remaining squares around it.

Introducing Territory

October 20, 2026

Launched "Territory — Full Takeover" (Game 5), a continuous territory-capture game. Pick a character and an arena, then claim the whole map against bots. It can also be added to a phone's home screen and played like an app.

Introducing Caravan & Crossblades

June 28, 2026

Launched "Caravan & Crossblades" (Game 4), a text-based RPG clicker set in a medieval world. Players can travel between towns, trade resources, and handle random combat/story events.

Implementing Dark Mode

June 18, 2026

Added automatic dark theme support across the entire site. The CSS detects system preferences, and Minesweeper redraws its canvas board with a dark palette when the system theme changes.

Minesweeper Experiment

June 1, 2026

Added a canvas-based Minesweeper clone as our third experiment. It features standard layout configurations (Beginner, Intermediate, Expert), right-click flagging for desktop, a tap-mode switch for mobile, and local storage state persistence.

Medieval Merchant Clicker

May 31, 2026

Overhauled the simple clicker game into "Medieval Merchant Clicker". The update introduced a full 10-tier career progression from Woodland Forager to Merchant Prince, automated upgrades, and compact number formatting (e.g., 1.6K, 56M).

Developing with AI

May 31, 2026

Since May 31, 2026, this website has been developed with the help of AI. I use it as a coding and writing assistant while keeping the site as my own personal workspace.

Creating this website

September 16, 2025

I decided to create my own web page. The first version is intentionally simple HTML.
